# Expense Tracker

A modern, responsive expense tracker with a Sunset Warm dark theme. Add your income and expenses, watch your balance update, and keep your data saved even after a refresh.

## Features

- Add income and expense transactions
- Live total balance, income and expense cards with progress bars
- Delete any transaction
- Data saved in localStorage, so it stays after a refresh
- Negative balance turns red so overspending is easy to spot
- Fully responsive layout for mobile, tablet and desktop
- Dark theme built with amber, orange and stone colors

## Tech Stack

- React (Vite)
- Tailwind CSS
- Context API (`useContext`, `useState`, `useEffect`)

## Getting Started

```bash
git clone https://github.com/YOUR-USERNAME/expense-tracker-react.git
cd expense-tracker-react
npm install
npm run dev
```
